Einstellungen im Code lesen

use PrstSearch\Plugin;
use PrstSearch\Settings\Settings;

$settings = Plugin::instance()->get( Settings::class );

$settings->string( 'mode' );              // "keyword", "semantic" oder "ai"
$settings->int( 'results_per_page' );     // 10
$settings->bool( 'hide_weak_results' );   // false
$settings->list( 'post_types' );          // array( 'post', 'page' )

Gespeichert sind alle Einstellungen gemeinsam in der Option prstsearch_settings. Fehlt dort ein Wert, gilt der Standard aus dem Schema.
